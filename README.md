Super Mario Bros. 3 HD – Xbox 360

Super Mario Bros. 3 para Xbox 360 (RGH)

Un port funcional de Super Mario Bros. 3 para Xbox 360, adaptado para ejecutarse directamente en la consola mediante RGH.

El proyecto permite disfrutar del clásico de NES en Xbox 360, con una presentación adaptada a la plataforma.

Características

- Port funcional para Xbox 360.
- Compatible con consolas Xbox 360 con RGH.
- Compatible con almacenamiento USB y HDD interno.
- Ejecución directa desde el menú de juegos de la consola.
- No requiere utilizar un emulador externo.
- Versión 1.0.

Instalación

1. Descargá el proyecto desde GitHub.
2. Descomprimí los archivos.
3. Copiá la carpeta del juego a tu dispositivo USB o al HDD interno de tu Xbox 360.
4. Conectá el dispositivo a la consola (si utilizás USB).
5. Escaneá la ruta donde copiaste el juego desde Aurora, Freestyle Dash o tu gestor de juegos.
6. ¡Listo! El juego aparecerá en tu biblioteca y podrás ejecutarlo.

Controles

START + BACK (mantener 2,5 segundos)| Salir del juego

Super Mario Bros. 3 HD – Xbox 360

Super Mario Bros. 3 for Xbox 360 (RGH)

A fully functional port of Super Mario Bros. 3 for Xbox 360, adapted to run directly on the console through RGH.

This project allows you to enjoy the NES classic on Xbox 360, with a presentation adapted to the platform.

Features

- Fully functional Xbox 360 port.
- Compatible with Xbox 360 RGH consoles.
- Supports USB storage and internal HDD.
- Direct launch from the console's game library.
- No external emulator required.
- Version 1.0.

Installation

1. Download the project from GitHub.
2. Extract the files.
3. Copy the game folder to your USB device or Xbox 360 internal HDD.
4. Connect the storage device to your console (if using USB).
5. Scan the directory where you copied the game using Aurora, Freestyle Dash, or your preferred game manager.
6. That's it! The game will appear in your library and you can launch it.

Controls

Buttons| Function
START + BACK (hold for 2.5 seconds)| Exit the game

Project Information

- Game: Super Mario Bros. 3
- Platform: Xbox 360
- Compatibility: RGH
